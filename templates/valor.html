💡 Sobre este desarrollo

Contabilización inteligente de transferencias bancarias

Un sistema que transforma el caos de los mensajes bancarios en información contable clara, auditable y accionable. No es una API bancaria: no obtiene saldos ni movimientos de efectivo. Es una herramienta de gestión que organiza, contabiliza y ayuda a conciliar.

🎯 ¿Qué es exactamente este sistema?

✅ Lo que SÍ hace:
  • Contabiliza y organiza los mensajes de texto bancarios.
  • Ayuda en la conciliación con el extracto bancario.
  • Detecta anomalías (pagos que no cuadran, montos inusuales, mensajes sospechosos).
  • Muestra claramente qué pagos están pendientes y cuáles confirmados.
  • Lleva control de qué dependiente o vendedor registró cada transacción.
  • Analiza cuentas propias y de terceros (cuánto se depositó, a quién se pagó).
❌ Lo que NO hace:
  • No se conecta directamente al banco.
  • No obtiene saldos ni movimientos de efectivo en tiempo real.
  • No reemplaza al extracto bancario oficial.
  • No procesa automáticamente el extracto (tú lo revisas y marcas).

Este sistema parte de una realidad concreta: los bancos cubanos envían mensajes de texto con cada transferencia, pero no ofrecen APIs para consultarlos. Los contadores deben leerlos uno por uno, anotarlos en Excel y luego cruzarlos manualmente con el extracto. Este desarrollo automatiza esa primera parte y asiste en la segunda.

⚙️ Funcionalidades principales

📥

Captura desde mensajes de texto

Parsea automáticamente el texto bancario y extrae fecha, monto, ordenante, beneficiario, N° de transacción y moneda.

🖼️

OCR para casos excepcionales

Cuando el mensaje no llega, permite subir una captura de pantalla. El OCR la procesa y el usuario puede corregir manualmente.

✅

Confirmación contra extracto

El contador revisa el extracto bancario y marca manualmente qué transacciones ya aparecen. El sistema actualiza el estado.

🔍

Detección de anomalías

Alerta de pagos pendientes por mucho tiempo, montos inusuales o registros que no coinciden con el patrón normal.

👥

Control por dependiente

Cada transacción queda asociada al vendedor o dependiente que la registró. Trazabilidad completa.

📊

Dashboard analítico

Estadísticas en tiempo real: total enviado, recibido, pendientes, confirmadas. Filtros por fecha, banco, moneda y estado.

📤

Exportación a Excel y PDF

Reportes profesionales con subtotales, agrupaciones y espacio para firma del contador.

📱

Escaneo QR de cédula

Extrae el nombre del cliente desde el QR del carné de identidad, evitando escritura manual.

💎 El valor diferencial

1. Resuelve un problema que no tiene solución comercial en Cuba

En el mundo desarrollado, bancos como BBVA o Santander ofrecen APIs (Open Banking) para que sistemas como Xero o QuickBooks hagan conciliación automática. En Cuba no existe nada parecido. Este sistema construye el puente que falta usando los mensajes de texto que ya llegan.

2. Convierte información dispersa en contabilidad ordenada

Lo que antes era una bandeja de mensajes y una hoja de Excel ahora es una base de datos consultable, filtrable, exportable y auditable. Cada transacción tiene un estado, un responsable y una fecha de confirmación.

3. Ahorra tiempo real al contador

La lectura y registro manual de decenas de mensajes diarios se reduce drásticamente. Lo que tomaba 2–3 horas puede hacerse en 20–30 minutos, con mayor precisión y menos errores.

4. Aporta trazabilidad y control interno

Saber quién registró qué transacción y cuándo es fundamental para negocios con múltiples puntos de venta o vendedores. Este sistema lo resuelve de forma natural.

5. Está diseñado para el contexto cubano

No asume APIs bancarias, ni extractos en formatos estructurados, ni conectividad perfecta. Trabaja con lo que hay: mensajes de texto, capturas de pantalla y extractos en PDF o papel.

🛠️ Tecnologías utilizadas

El sistema está construido con herramientas modernas que garantizan rendimiento, validación estricta de datos y facilidad de mantenimiento.

⚡ FastAPI ✅ Pydantic 🗄️ SQLite 🔍 OCR (Tesseract) 📷 html5-qrcode 📊 SheetJS (Excel) 📄 html2pdf.js 🌐 Cloudflare Tunnel

¿Por qué estas tecnologías?

  • FastAPI: framework asíncrono de alto rendimiento, ideal para APIs que procesan texto.
  • Pydantic: validación estricta de datos. Evita que lleguen montos, fechas o números de transacción mal formados a la base de datos.
  • SQLite: base de datos ligera, portable, sin servidor, perfecta para un sistema que puede correr en una PC modesta.
  • Tesseract OCR: reconocimiento óptico de caracteres para el pequeño porcentaje de casos donde el mensaje no llega.
  • Cloudflare Tunnel: expone el sistema con un dominio fijo y HTTPS sin necesidad de abrir puertos ni pagar hosting.
💡 Dato técnico: el uso de Pydantic con validación estricta es clave en un contexto donde los mensajes bancarios pueden venir con formatos ligeramente distintos. Pydantic garantiza que los datos lleguen consistentes a la base de datos, evitando errores silenciosos.

🚀 Un puente entre el banco y la contabilidad

Este sistema no pretende reemplazar al banco ni al contador. Pretende ser la herramienta que hace su trabajo más rápido, más ordenado y más seguro, aprovechando lo que ya existe: los mensajes de texto que el banco envía.
